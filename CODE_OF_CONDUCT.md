# Code of Conduct

## Our commitment

We want this project to be a respectful, useful, and calm place to collaborate.

Contributors, reviewers, and maintainers are expected to:

- be respectful in disagreement
- focus on evidence and reasoning
- assume good intent while staying honest
- avoid personal attacks, harassment, and pile-ons
- keep feedback actionable and relevant to the work

## Expected behavior

- Use welcoming and professional language.
- Be specific when giving technical criticism.
- Respect different experience levels.
- Prefer clarification over dismissal.
- Accept correction gracefully.

## Unacceptable behavior

- harassment, insults, intimidation, or discrimination
- doxxing or sharing private information
- deliberate bad-faith misrepresentation of someone’s work
- spam, trolling, or hostile derailment

## Enforcement

Project maintainers may remove comments, close discussions, or block contributors whose behavior harms the project or other participants.

## Scope

This code of conduct applies to:

- issues
- pull requests
- code review discussions
- repo-linked public discussions about the project

## Reporting

If you run into a conduct issue, open a private channel with the maintainer rather than escalating publicly in the middle of a technical thread.

## Practical note

This is a technical repository for careful, evidence-driven work. Strong disagreement is fine. Disrespect is not.
