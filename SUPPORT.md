# Support

This repository is maintained as an open-source engineering project, not a commercial support product.

## Best way to get help

- Open an issue for reproducible bugs or documentation gaps.
- Open a discussion/issue for design questions or roadmap suggestions.
- For security concerns, use the process in [SECURITY.md](./SECURITY.md).

## Good support requests include

- what you were trying to do
- exact command run
- expected behavior
- actual behavior
- relevant log or traceback
- environment details if relevant

## Please avoid

- “it doesn’t work” with no reproduction
- requests for hidden proprietary insurer data
- requests to use the repo as a source of legal advice

## Maintainer bandwidth

This project was built as a focused side project and research artifact. Responses may be selective and slower than a commercial product would provide.
